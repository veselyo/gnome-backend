Requirements

  • macOS 11.0 (Big Sur) or later
  • Voyage AI API key (Get one here)
  • Pinecone API key (Get one here)
  • ~200MB disk space
  • Internet connection for first setup

Quick Start Guide

  1. Download Gnome.dmg
  2. Open the DMG and drag Gnome to Applications
  3. Right-click Gnome.app → Open
  4. Enter your Voyage AI and Pinecone API keys
  5. Upload PDFs and start searching!
